# 🌺 Contributing to shakaleikaumaka.com

**Yes — PRs are open to friends, family, and every kind human.** 🌍

This repo isn't a mirror. **This repo IS the website.** When a PR merges to `main`, shakaleikaumaka.com updates automatically within ~1 minute (GitHub Pages). What you merge is what the world sees.

## How to play
1. **Fork** this repo 🍴
2. Make your change — fix a typo, improve accessibility, tune the design, translate something, suggest a verse
3. Open a **Pull Request** — it gets reviewed with aloha, right here on GitHub
4. Watch it go live at [shakaleikaumaka.com](https://shakaleikaumaka.com) 🎶

## The house rules (the only rules)
- **Personal story edits** (bio, photos, the songs' lyrics) come from Shaka himself — everything else is fair game: typos, code, design, accessibility, translations.
- **No names on the page** beyond what's already there — credit lives in commit history.
- **Everything is CC0** — by contributing, you agree your work joins the commons.
- **Heart first, always.** 🌺

*"github.com/shakaleikaumaka — fork me like crazy."*
